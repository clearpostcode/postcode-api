A postcode finder on any form, in one line

Type a postcode: it is formatted as you go, checked against every UK postcode, and the council, county and constituency fill themselves.

  • Suggestions as you type, full keyboard use and screen-reader announcements
  • A clear message for a mistyped, retired or brand-new postcode
  • Address lookup on Royal Mail PAF: with a key that has it switched on, the same box finds the full address
  • About 8 KB gzipped, no dependencies, themed with CSS variables

Add it to your form

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/clearpostcode@2/dist/widget.css">
<script src="https://cdn.jsdelivr.net/npm/clearpostcode@2/dist/widget.js"
        data-key="cp_pub_..." defer></script>

Every input with autocomplete="postal-code" (or data-clearpostcode="postcode") gets the finder. Mark other fields with data-clearpostcode="council", "county", "constituency" and so on. The key is optional in postcode mode. Docs: the finder's guide.
